# ADR-002: Solver Optimization vs. Official Validator Boundary

## Status
Accepted

## Context
The platform must generate weekly schedules (189 sessions, 243 hours) and midsem exam schedules (41 exams) that satisfy 100% of institutional constraints without errors. The hackathon provides an official `validator.py`.

## Decision
1. **Solver Technology**: Google OR-Tools CP-SAT is chosen for its superior performance on discrete constraint satisfaction problems (CSP) and integer programming.
2. **Validator Independence**: We strictly DO NOT replace, modify, or simulate `validator.py`. The official validator serves as an independent external verification gatekeeper.
3. **Execution Boundary**: All candidate schedules generated by OR-Tools must pass the official validator with 0 hard violations before being saved, published, or exported.

## Consequences
- Guarantees zero regression against hackathon scoring criteria.
- Protects the system against hallucinations or heuristic errors.
